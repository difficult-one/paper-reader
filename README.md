# 论文对照阅读器

支持任意两份 PDF 双栏对照、联动翻页/滚动/缩放、选字询问、高亮和文字备注，以及阅读位置恢复的 Windows 桌面阅读器。

0.1.16 启动时恢复上次打开的论文和阅读位置，改进连续拖选文字的准确性，并支持点击选区工具栏以外的位置取消选择。

0.1.15 阅读界面新增可收起的章节目录：按 PDF 内置书签的层级显示章节，点击标题跳转，子章节可独立折叠；双栏可选择左侧或右侧目录。没有内置目录的 PDF 提供页码导航。

0.1.14 增加对照栏直接拖入：从桌面、资源管理器或应用内列表把 PDF 拖到左侧或右侧，即可补充或更换该侧论文。支持两篇中文、两篇英文以及混合语言，栏头显示各自文件名。

0.1.13 增加可折叠的论文列表。连续拖入 PDF 会依次追加，点击列表切换，各篇独立保留阅读位置、缩放、阅读模式、中英配对及批注。

0.1.12 移除自动全文翻译，保留对照观看、联动阅读和 API 问答。安装包不再附带翻译引擎及 Python。已有本地配对、批注、问答记录与加密 API 配置继续使用；旧版生成的译文缓存仍可恢复，也可手动导入已有中文 PDF。

## 使用

1. 运行 `PaperReader-Setup-0.1.16.exe` 安装。已有版本退出软件后可直接升级，本地记录保留，无需安装 Python 或 Node.js。
2. 点击“打开论文”（Ctrl+O），或将 PDF 拖入窗口，即可阅读、选字高亮及添加备注。阅读与批注无需 API。
3. 点击“导入对照论文”（Ctrl+Shift+O），或同时拖入任意两份 PDF，确认左右顺序后点击“开始对照阅读”。也可先打开一篇，再切换“双栏对照”，把另一篇从桌面或资源管理器拖到右侧。左右两栏均支持单份 PDF 直接拖入，替换一侧时保留另一侧。列表条目也可直接拖到任一侧，使用已保存的快照。配对和 PDF 快照保存在本机。
4. 可切换单栏左侧、双栏对照和单栏右侧。“联动阅读”开启时同步翻页、滚动和缩放；关闭后两侧独立操作。页数不一致时关闭联动。拖动中线调整栏宽。
5. 鼠标位于 PDF 上时，按住 Ctrl 滚动滚轮缩放，范围 50%～300%；也可使用栏顶部缩放下拉框。Ctrl+0 适应宽度。阅读位置、缩放与栏宽自动保存。
6. 选中文字点击“询问”，或按 Alt+Q。配置“API 设置”后可输入问题，或选择“解释术语”“解释这句话”“在本文中有什么作用”。Enter 发送，Shift+Enter 换行。支持追问、停止、重试、复制、保存为备注及本机会话管理。通过校验的出处可点击返回对应版本的页面；原文和中文不会按相同页码强行配对。
7. “API 设置”保留服务地址、加密密钥、获取模型、手填模型 ID、测试连接、每秒请求数和 DeepSeek 思考档位。接口需兼容 Chat Completions，基础地址无需添加 `/chat/completions`。根地址自动补充 `/v1`，自定义路径保持原样。测试连接会发送小请求，可能计费；获取模型仅请求 `/models`。同一地址下可留空复用已存密钥，更换地址需填写对应密钥。
8. 浮动工具栏提供四色高亮和“添加备注”。“批注”侧栏支持编辑、换色、删除及回到原位置。Ctrl+Z 撤销本次会话的批注操作。“另存右侧”可将当前右侧 PDF 另存到新位置；批注单独保存在本机，不嵌入 PDF。软件阻止覆盖原文和配对的导入源文件。
9. 左上角“论文”按钮显示本次打开的论文数量，点击展开或收起左侧竖向列表。连续拖入的单篇 PDF 会追加，即使上一篇正在打开也会排队处理；重复打开相同内容不会增加条目。点击任意论文恢复它的阅读状态。条目右侧 × 仅从当前列表关闭，不删除 PDF、阅读记录或批注，重新打开 PDF 后仍会恢复记录。当前打开列表属于本次应用会话。
10. 点击“目录”展开左侧章节目录，点击章节标题跳到对应页及页内位置，点击章节前的箭头展开或收起子章节。“目录”按钮、栏内的收起按钮或 Esc 均可收起目录并恢复阅读宽度。目录与论文列表共用左侧空间，切换时自动收起另一栏；双栏时使用“目录来源”选择对应论文，跳转遵循当前联动设置。目录只使用 PDF 自带书签，不调用 API；无内置目录时可按页码跳转。

## 快捷键

按 F1 或右上角键盘图标查看完整列表。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+O / Ctrl+Shift+O / Ctrl+逗号 | 打开论文 / 导入对照论文 / API 设置 |
| Alt+1 / Alt+2 / Alt+3 | 单栏左侧 / 双栏对照 / 单栏右侧 |
| Alt+L | 切换联动阅读 |
| Alt+A / Alt+Q | 批注侧栏 / 询问选中文字或切换问答侧栏 |
| Alt+H / Alt+N | 选字高亮 / 备注 |
| Ctrl+Z | 撤销批注操作；输入框内撤销文字 |
| Ctrl+G | 聚焦页码，Enter 跳转 |
| Ctrl+PageUp / Ctrl+PageDown | 上一页 / 下一页 |
| Ctrl+加号 / Ctrl+减号 / Ctrl+0 | 放大 / 缩小 / 适应宽度 |
| Esc | 取消选区、关闭侧栏或弹窗 |

跳页和缩放作用于最近操作的阅读栏；联动时两栏同步。输入文字或设置时不触发阅读与批注快捷键。

## 数据与隐私

- 阅读、配对、批注、PDF 解析和问答文本索引在本机完成。发送问题时，服务商收到问题、选中文字、相关论文片段及必要的追问上下文。
- API 密钥使用 Electron safeStorage（Windows DPAPI）加密保存，界面不会读回已存密钥。
- 设置与记录位于 `%APPDATA%/paper-reader`，可在“API 设置 → 关于软件 → 打开本地数据目录”查看。
- 配对位于 `documents`，批注位于 `annotations`，问答会话、索引和缓存位于 `questions`、`question-index`、`question-cache`，累计用量位于 `question-usage.json`。删除问答会话保留论文、批注和累计用量。
- 问答显示请求次数和输入/输出 token。服务商未完整报告的用量不视为免费，未配置单价时不推算金额。
- 安装、升级及卸载保留本地数据。不要将密钥或敏感论文缓存发送给他人。

扫描 PDF 可以浏览，但选字询问和批注需要先 OCR。选区超过 2,000 字符时需缩小范围。图表或扫描件证据不足时，问答会提示补充内容；回答及引用仍需结合论文核实。

## 开发与构建

开发机需要 Node.js 24 或更新版本和 Windows x64。

```powershell
npm ci
npm run dev
npm test
npm run build
npm run test:ui
npm run test:outline
npm run package
npm run test:installer
node scripts/verify-package.mjs
```

`test:ui` 验证配对、联动、API 设置、问答、快捷键、多篇论文切换、左右拖入和章节目录；`npm run test:outline` 单独验证目录展开收起、子章节、命名目标及页内位置、双栏来源及联动、无目录回退和重启恢复；`npm run test:pair-drop` 验证外部文件拖入、列表拖入、中中/英英对照及替换保护；`npm run test:documents` 单独验证论文列表、连续拖入、独立阅读进度与批注、关闭重开和重启恢复。问答使用本地模拟服务，不消耗真实 API 额度，也不能据此评价真实模型的事实准确度。

构建后可用 `npm run test:inspection` 检查 300 页 PDF 元数据解析时主进程是否保持响应。`node scripts/reader-performance-matrix.mjs --label-prefix=reader-matrix` 依次测量长文本、扫描页、复杂矢量、混合尺寸及大量批注与流式回答的滚动性能，原始帧、输入反馈、内存及结果保存在 `output/playwright/reader-matrix`。这些是本机受测场景的结果，不代表任意设备、PDF 或远程服务都没有延迟。

安装包输出到 `release/PaperReader-Setup-0.1.15.exe`，解包版位于 `release/win-unpacked`。许可证及对应源码随安装包提供。项目保留旧翻译引擎源码、缓存兼容逻辑及历史验证脚本；它们不是当前应用的自动翻译入口。
