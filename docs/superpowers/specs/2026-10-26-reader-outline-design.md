# 可收起的章节目录

用户已确认：在 paper-reader 阅读界面左侧增加章节目录，可点击跳转，并且可以收起。

- 顶部增加“目录”开关，目录栏内也有收起按钮；收起后释放阅读宽度。与已有论文列表共用左侧空间，打开一栏时收起另一栏。
- 复用当前 PdfPane 载入的 PDF.js 文档，按 PDF 内置书签的层级显示章节，子章节可独立折叠。目录不请求 API，也不重新解析整份 PDF。
- 双栏时可选择左侧或右侧的目录；单栏只显示可见一侧。目录跳转沿用现有联动和阅读位置保存逻辑，支持命名目标、页面引用和页内位置。
- 没有内置目录时说明原因并显示页码导航。目录载入和章节定位失败时在目录栏内显示可恢复提示，保留 PDF 阅读。
- 延续现有浅色、绿色强调、Lucide 图标与侧栏尺寸。长标题自动换行，窄窗口沿用辅助面板的覆盖布局，按钮支持键盘操作。

验证：使用带嵌套书签和命名目标的真实 PDF 验证展开、收起、章节跳转、左右选择、联动、无目录回退、论文切换与阅读位置保存；运行构建和现有相关回归测试。
