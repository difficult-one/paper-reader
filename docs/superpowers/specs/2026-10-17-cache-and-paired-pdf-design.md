# 缓存优化与本地双 PDF 对照

用户已确认输入为两份 PDF，并明确选择“按推荐方案实施”。这份文件记录已批准的方案；无需再次审批。工作目录没有 Git 元数据，保留文件而不初始化仓库。

## 缓存

参考官方 DeepSeek Harness 的稳定请求前缀和规范表示，保留独立翻译请求，不追加多轮历史。现有网关仅分离正文批翻译模板，术语提取未覆盖；条件性术语规则位于动态消息开头，削弱同文档标题的前缀复用。改为识别已知上游模板，将固定规则、示例放入稳定前缀，标题置于术语表及正文前，单段翻译也分离固定指令。正文、术语表、占位符和输出规则完整保留；无法可靠识别的请求原样转发。

本地缓存对对象键作确定性序列化，保持数组、正文和模型参数顺序及数值意义；不同服务、模型、思考档位继续隔离。兼容已有请求缓存。只有经过输出结构验证的完整成功结果才计为本地命中，错误合并不能伪报命中。补齐术语提取 JSON 验证。保留开启思考的 low/high/max 和现有输出预算。

验收以本地 HTTP 测试验证前缀稳定、正文无损、对象键顺序不导致重复请求、缓存隔离及错误行为。服务端命中率只使用真实 usage，不承诺百分比，不调用用户付费服务做验证。

## 本地对照阅读

工具栏和首页增加“导入中英对照”，打开简洁对话框，分别选择英文原文、中文版本，可交换左右，再确认打开。同时拖入恰好两份 PDF 打开同一对话框，按语言检测建议顺序，但最终由用户确认；拖入一份仍按原逻辑打开。已打开原文时可直接补充中文版本。

两份文件先验证，再复制到应用数据目录并原子写入配对记录。左侧文档哈希作为论文标识，右侧内容哈希作为导入版本标识，复用原文批注，并隔离不同中文版本的批注。重新打开同一英文 PDF 能恢复本地配对，与 API 配置无关。导入配对优先于模型翻译缓存；用户显式翻译时可以切换当前会话，但不覆盖导入文件。

页数相同时支持现有同步页码、滚动和缩放；页数不同时自动关闭联动并说明，可独立阅读和批注。沿用单栏/双栏模式、阅读位置保存和导出；导出的来源必须为当前显示版本，且不能覆盖任一导入源文件。扫描 PDF 允许对照浏览。损坏、加密、同一份文件重复导入等错误在提交前显示，取消不会切换当前文档。

不增加 Word/EPUB、自动段落对齐、跨页语义匹配或在线上传。
