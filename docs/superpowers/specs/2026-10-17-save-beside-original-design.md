# 译文保存到原文目录

用户明确要求把现有译文及以后生成的对应译文放到被翻译文档所在目录，作为本次保存规则的实施授权。

采用自动复制已验证的中文 PDF 到原文目录的方案，内部缓存继续用于恢复和重试。文件名为 `<原文名>.中文译文.pdf`。不覆盖源文件及任何不同内容的同名文件；同内容复用，不同内容依次使用 ` (2)`、` (3)` 等后缀。原目录不可写时，翻译本身仍算成功，明确提示缓存可用及需要“另存译文”。

首次翻译完成、点击翻译复用缓存、重新打开具有生成译文缓存的原文都确保旁边有中文副本。外部副本的实际路径记录在会话中，完成提示显示保存位置；导入已有中文 PDF 的流程不复制、不改变其配对。

为后续恢复，在原文快照目录保存源路径元数据；已有记录根据已验证的导入配对路径定位。当前译文复制前核实源文件哈希与翻译缓存对应，且保留内部缓存副本。

验证包括自动输出、缓存复用与重开、重名保护、相同输出复用、原目录不可写仍可阅读，以及实际 Electron 完成提示与输出文件。交付更新后的 0.1.6 安装包。
