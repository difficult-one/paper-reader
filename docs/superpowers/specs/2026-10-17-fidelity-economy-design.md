# 保真省钱翻译设计

用户已选择“保真省钱：兼顾忠实度与费用”，并要求继续实现。主对话负责生产主流程、设置、预算和打包；另一对话负责风险与结果复核。术语合批实验保持隔离。

## 行为

新增显式翻译策略 economy / manual。新配置默认 economy；旧配置未记录策略时维持 manual，以保留既有思考选择和译文缓存。用户可在设置选择“保真省钱（推荐）”或“手动思考档位”。本次用户选择的 economy 在新版本设置中可保存。仅 DeepSeek 官方接口的已知翻译/术语模板使用 economy：第一次请求 low，仍开启思考，保留全部规则、术语、完整上下文和服务商默认输出预算。未知模板、第三方接口沿用原行为。manual 保持 low/high/max 选择。

新增确定性校验：占位符与标签结构沿用现有保护；额外比较数字表达、正负号、比较符号和百分号，允许 Unicode 负号、数字千位空格/逗号、科学计数写法及标点空格规范化。公式占位符、标签属性、DOI/URL 不作为普通数值。数字重排允许但数值、科学计数指数及符号必须对应。此检查只发现部分可检测问题，不把通过称为语义保真，不尝试用关键词猜测否定或证据强度。

对可解析且自然结束的批量响应，保留所有通过校验的段落；仅把异常或缺失条目升级 high 至多一次，始终附上完整原始有序源批次、标题、词表及规则。不能解析/截断时不猜测部分成功，至多一次整批 high 修复。修复后仍不合格明确返回失败，同任务内相同逻辑请求不再重复付费修复。首次请求的 429、鉴权、网络故障不触发质量升级；已经开始的 High 修复若返回 HTTP 错误，保留状态/重试头，连接中断则明确标为费用及结果未知，同任务不再次付费，用户新任务可续跑成功段落。single / terminology 可检测失败时至多一次 high；术语不合并、不跳过。

economy 请求与段落缓存包含策略版本和模式，读写均执行对应校验。完整成功译文保留复用；升级仅在原规则与布局兼容时允许读取旧完整 PDF，实际沿用旧 translationKey 维持批注。手动模式缓存键不变。成功段落不被修复结果覆盖。用量统计包含首次无效响应和 high 修复，界面说明模式不保证固定节省或零误译。
