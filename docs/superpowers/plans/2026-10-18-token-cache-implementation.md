# Token 缓存与成本优化实施计划

**目标：**实施提案 01 的 A 路线，在现有网关上提供可解释计量、局部术语复用、受控思考实验和译文回放。

**架构：**默认 baseline 保留现有 economy/manual 行为。`PAPER_READER_TRANSLATION_STRATEGY=terminology|adaptive` 显式启用实验；策略进入 PDF、段落、术语和中间结果的兼容范围。所有实验先离线，真实请求另需明确预算。

**约束：**不接入 Harness；不改变 600 token 术语合批边界；不清理旧缓存；不降低输出上限；一次修复后停止；本地复用不计为服务端命中。当前目录无 Git 元数据，不创建提交。

- [x] P0：扩展 `cache-diagnostics.ts`，按任务类型及 primary/repair/semantic-review 阶段记录输入、内容、思考和费用未知数；新增 `translation-cost.ts`，使用显式价格，思考不重复收费。
  - 测试：完整/缺失/异常 usage、输出拆分、修复费用、零调用复用。
- [x] P1：新增 `document-terminology.ts`，保存来源片段、局部语境、定义线索、文档/策略/模型范围和版本。按完整原始术语提取批次复用；新增章节仍按本章批次提取候选，参考旧译法但不强制合并定义。
  - 测试：后文改变定义时不部分复用、空结果完成标记、定义冲突、生成参数、并发/损坏文件、重新启动、文档与策略隔离。
- [x] P2：新增 `translation-strategy.ts`，非思考仅适用于官方已知模型的清晰定义术语；普通正文 Low，否定/条件/统计/公式/歧义段定向 High 复核并保留原上下文，失败最多升级一次。
  - 测试：兼容服务不注入参数、默认策略不变、模式隔离、风险段抽检、修复与复核次数上限、截断失败。
- [x] P3：新增 Python `reader_replay.py`，保存带源映射的翻译后 IL，精确匹配提取版本和源 IL 后回放并继续排版；不匹配/损坏回退现有路径，取消不提交新结果。回放链接旧质量报告，不宣称重新语义验证。
  - 测试：真实 BabelDOC 数据模型的序列化与回放、源/策略隔离、取消、损坏文件，以及现有完整 PDF 零请求重开回归。
- [x] 实验入口：提供确定性随机顺序、本地冷/热状态、三次重复、独立费用上限和盲评导出；默认离线，报告样本覆盖及语义/版面未验收状态，未达质量与经济目标不宣称成功。费用预留持久化，未知 usage 停止请求；旧实验目录禁止重跑。
- [x] 验证：运行新增测试、全量 Vitest、Python 适配测试和构建；独立审查发现的语境、预算字段和冷态污染问题均已修复。
