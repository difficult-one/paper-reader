# 阅读器性能实施记录

依据：`docs/proposals/2026-10-18/03-reader-performance.md`，用户已授权实施。

目标：在现有 PDF.js、原生滚动、双栏定位及批注架构上统一调度画布与文本工作，限制缓存，增加可重复的帧耗时门禁。保留页面槽和跨页选区；未测量证明必要前不进行页槽虚拟化或替换 PDF 引擎。

- [x] 核查源码、构建及现有 158 项测试；记录当前构建滚动基线。
- [x] `pdf-render-scheduler.ts`：动态优先级、等待提升、AbortSignal/generation 校验、共享画布/文本/后台队列及 dispatch 耗时统计。测试可见页抢占、取消与公平性。
- [x] `pdf-page-cache.ts`：有容量上限的资源 LRU、固定可见/选区/绘制中资源、文本与尺寸缓存、像素预算与内部回退开关。测试淘汰、拒绝超额及绘制完成后释放。
- [x] `pdf-page-visibility.ts`、`PdfPage.tsx`、`PdfPane.tsx`：每栏共享观察器；冷页低分辨率预览，静止后仅升级可见高清与文本；保留旧画面、活动选区与拖选锚点；缩放稳定后重绘；尺寸后台加载；批注按页索引。
- [x] `App.tsx`：稳定阅读栏 props 和 memo 边界，避免后台状态触发阅读栏更新。保留已有日志长度上限与日志限频。
- [x] `scripts/scroll-smoke.mjs` 与独立采样模块：保存原始帧/长任务/输入/冷页/内存数据，加入 P95/P99、慢帧、长任务失败条件；支持 60 秒 × 3 和 10 分钟整篇到底再回顶、输入速率有效性、DPR/夹具/安装版参数及 trace。
- [x] 构建、单元与真实 Electron 回归；按代码审查技能请求独立审查并修复已确认问题；完成三轮 60 秒和 10 分钟整篇往返，记录实测、支持范围与尚未完成的外部验证。详见 `docs/proposals/2026-10-18/03-reader-performance-validation.md`。
- [x] 发布门槛：最终程序超长帧、冷页、选区和文档矩阵已通过；0.1.11 安装包实际提取、13,249 个共用运行文件一致性核对及提取版画面/问答/选区复测均通过。物理低内存/触控板等外部设备明确列为未验证范围。

验证原则：基线与改后使用同一文件、窗口和设备；原始坏帧保留。性能门禁失败不降低阈值掩盖。当前机器不是用户问题机器；没有完成的设备、触控板、真实服务并发及复杂文档测试明确列出。
