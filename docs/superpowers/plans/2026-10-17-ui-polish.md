# 论文阅读界面美化

**Goal:** 落实用户选择的暖白与墨绿界面，改善首页、阅读栏、批注和设置的可读性。

**Design reference:** awesome-design-md 的 Notion 分析，仅借鉴中性色、字级、间距和控件规范；保留软件现有墨绿品牌。使用 impeccable 的 Operate 模式及 polish 流程。

**Architecture:** 修改共享 CSS 与首页表现性 JSX。保留 Electron、IPC、翻译引擎、数据存储和 PDF 排版逻辑。字体使用本地 Segoe UI / Microsoft YaHei UI，不下载 Notion 专有字体。

**Tech stack:** React、CSS、Lucide、Electron、Playwright。
