# 多篇论文列表实施计划

**目标：** 按已批准的样图增加可折叠列表；连续拖入论文追加并可切换，每篇独立保留阅读位置、缩放、模式、中英配对及批注。

**架构：** 渲染进程维护当前会话的论文列表，沿用内容哈希作为论文身份，复用主进程现有的阅读记录和批注存储。切换前等待批注提交并保存阅读状态，仅挂载当前论文的阅读器，避免后台论文占用渲染资源。连续单文件拖入排队处理；原有同时拖入中英两份 PDF 的配对流程保留。

**技术：** React / TypeScript / Electron，沿用现有 CSS 和 lucide-react。无 Git 元数据，原文件备份至 output/paper-list-backup-20261020。

## 约束

- 当前打开列表属于本次应用会话；关闭列表条目不删除 PDF、阅读记录或批注，重新打开仍恢复已保存的记录。
- 同一内容重复打开只更新既有条目；一篇的中英文版本保持一个条目。
- 保存或打开失败时保留现有论文及列表，提供可见错误；连续拖入不因已有打开任务被忽略。
- 界面沿用米白和深绿；论文按钮含数量，展开列表有当前项、阅读页码、关闭和添加入口。窄窗口避免列表与批注重叠遮挡阅读器。
