# 鼠标中心缩放与交互响应

目标：Ctrl + 滚轮缩放时保持鼠标指向的 PDF 内容在原屏幕位置，并减少连续缩放时的主线程与栅格化工作。沿用现有缩放档位、上下限、联动和保存逻辑。

方案：滚轮输入累计到下一刷新帧，记录鼠标对应页面中的归一化坐标。连续缩放时通过内容容器的 CSS transform 即时预览，页面组件沿用原有比例与栅格；停止输入 150 ms 后再提交页面比例并重绘。布局提交时按鼠标锚点补偿横纵滚动；清晰重绘完成时再次保持同一锚点。独立栏只改变当前栏，联动时同步缩放及阅读位置。
