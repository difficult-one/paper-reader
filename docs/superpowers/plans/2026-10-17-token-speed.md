# Token 速度与缓存命中显示

**Goal:** 在已有翻译状态栏补充平均输出 token/s 和服务端命中 token 数，参考用户截图中的速度及缓存信息。

**Definition:** 非流式接口在完整响应后返回用量。平均输出速度等于已完成、提供有效 completion_tokens 的远端请求的输出 token 总数除以这些请求各自的完整耗时总和；包含服务等待、思考及返回正文时间，并发请求分别计时。本地缓存及并发去重不增加远端输出或耗时，PDF 解析与排版不计入。没有可用样本时显示“待统计”，缺少服务商缓存数据时显示“未提供”。不伪装为逐 token 的实时生成速度。
