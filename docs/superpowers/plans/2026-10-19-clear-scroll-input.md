# 缩放输入延迟与滚动清晰度

用户要求：进一步消除缩放时的鼠标延迟，滚动页面时不显示低清预览，保留鼠标中心缩放。

根因证据：在实际论文上进行快速连续输入与八组慢速逐格缩放、持续移动指针的混合测试，原实现出现 62 ms 主线程长任务、指针事件最大延迟约 49 ms。Chrome trace 定位到重建文字层后的样式计算、布局及绘制，单次主线程任务 62.456 ms。滚动测试实际采样到低清 canvas，失败用例已保存。缩放时现有文字节点被替换的回归用例也已失败。

方案：页面文字不变时保留首次构建的文字层，在文字层容器上同步比例，不再按缩放倍率重建所有文字节点。取消 preview 质量分支，首次和后续页面均按清晰质量渲染；滚动过程中保留已有清晰栅格，并推迟非可见页面的工作，避免高分辨率预取与指针输入竞争。
