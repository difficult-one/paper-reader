# 科研翻译排版与滚动优化

**Goal:** 修复参考文献编号条目合并，降低双栏长 PDF 滚动开销，将科研翻译 skill 接入实际模型请求并交付可安装版本。

**Architecture:** 保留 Electron、PDF.js 和现有 BabelDOC。缓存页面几何数据、隔离页面重渲染、限制画布开销；使用随软件分发的 Python 入口，在上游段落识别完成后按连续编号和几何对齐拆分独立条目，不修改第三方运行时。科研规则在固定 system 前缀中生效，批次 JSON 结构和文档术语上下文保留。翻译流程版本更新以隔离旧版错误排版缓存。

**Constraints:** 保留 API 思考档位；不调用用户付费 API；不修改用户已有 PDF、配对及批注。测试使用隔离数据目录、本地模拟服务和本机原文的只读副本。不声称 skill 能保证模型绝对准确或所有设备恒定帧率。

## 验证结果

- 83 项 TypeScript 单元测试和 6 项真实 BabelDOC 数据/Windows spawn 初始化测试通过。先复现编号合并、线性定位开销、单段回退漏用规范及旧缓存误复用，再验证修复。
- 原论文参考文献页的 17 条文献独立进入模型请求，最终 PDF 检出 17 个不同 y 位置的编号；合成测试检出 6 条。所有 API 为本地模拟。
- 96 页双栏 200 帧往返：逐页几何读取 114,624 → 0；开发构建 p95 帧间隔约 23.6 → 16.8 ms；打包程序复测 p95 20.1 ms、超过 50 ms 的帧 0 个。环境负载有波动，不宣称恒定帧率。
- 打包程序验证长文档翻页联动、缩放、窗口变化位置保持、两侧独立阅读及高倍率画布像素预算。源码与打包版均通过实际翻译引擎、双栏、选字批注、重启恢复及中文单栏回归；源码导入配对/设置回归通过。
- 独立只读审查发现单段回退模板缺少规范，已补入相同规则并通过缓存隔离测试；Python 适配器复审未发现剩余重要问题。skill 验证及 Impeccable 检查通过。
