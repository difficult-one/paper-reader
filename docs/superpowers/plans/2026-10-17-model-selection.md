# API 模型选择修复计划

目标：填写服务地址与密钥后，点击“获取模型”读取兼容接口的模型列表，选择时填写真实 API ID；保留手动填写模型。沿用已经授权的 API 配置与安装交付范围。

采用服务商实时返回的列表，避免内置固定模型过期；没有模型列表接口时提示手动填写。模型名称和 API ID 同时显示，提交只用 ID。获取列表无需先填模型。切换地址或密钥清空列表，等待请求期间禁用修改，防止使用旧服务商的结果。

密钥仍仅由主进程使用。已保存密钥只允许在同一基础地址留空复用，切换地址需输入对应密钥。请求失败显示脱敏后的服务商错误，并保留 HTTP 状态码。
