# 对照栏直接拖入实施计划

**目标：** 在双栏对照时，任意语言的两份 PDF 均可比较；支持从桌面、资源管理器以及应用内论文列表拖入左右栏。

**架构：** 在左右阅读栏外增加局部拖放容器，单文件事件在容器处理并停止向全局冒泡。新增 importSide 接口，使用已打开文件快照补充或更换任意一侧，不依赖已移动的源文件。复用原有内部版本键和本地存储以兼容旧记录。两份文件同时拖入继续使用配对对话框，按拖入顺序指定左右；其他区域的单文件拖入继续追加论文。界面统一使用左右侧名称和各自文件名。

**技术：** React / TypeScript / Electron，沿用现有样式和图标，不新增依赖。原文件备份于 output/pair-drop-backup-20261020；工作区无 Git 元数据。
