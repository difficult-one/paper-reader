# 连续滚轮联动卡顿修复

**Goal:** 降低持续滚轮及鼠标移动时双栏 PDF 绘制造成的主线程争用，保持页码、页内位置、选字和批注功能。

**Evidence:** 原始 96 页论文双栏的 360 次真实滚轮和鼠标移动，在本机约 9 秒内记录 12 次 50–55 ms 主线程任务。CPU 采样集中于 fillText、画布初始化、图像与文字层操作。当前各 PdfPage 独立调度 PDF.js 绘制，不能限制两栏同帧绘制总量。

**Architecture:** 两栏共用一个可取消的 FIFO 帧队列，每帧放行一个 PDF.js onContinue 回调。页面离屏、缩放或文档切换时移除待绘制任务。保留既有页面虚拟化与 8MP 画布上限。先单独验证此变化，不同时更换渲染后端或滚动策略。

**Files:** 新增 `src/renderer/src/pdf-render-scheduler.ts` 和 `tests/pdf-render-scheduler.test.ts`，修改 `src/renderer/src/PdfPane.tsx` 与 `scripts/scroll-smoke.mjs`。

- [x] 给实际双栏滚轮场景统计每帧绘制的画布数，记录原版本结果；集成测试先在原版本因同帧两个画布失败。
