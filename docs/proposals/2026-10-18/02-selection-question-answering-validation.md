# 选区问答实施与验证

更新：2026-10-19。对应 [原方案](02-selection-question-answering.md) 第一期。用户补充的交互已落实为：选中词语、句子或段落后，选区旁出现放大镜“询问”，点击后冻结选区、打开问题输入；仅选中或打开面板不会调用模型。

## 已实现

- 原文、中文原论文和导入中文版本共用现有选区和归一化坐标；支持快捷问题、自定义问题、Enter/Shift+Enter、Alt+Q、Esc 与焦点恢复。
- 问答和批注共用辅助区；宽窗侧栏 380 px，窄窗覆盖抽屉 360 px。内容独立滚动，最小 1000×680 窗口仍可使用输入、发送/停止和状态提示；不做逐帧宽度动画。
- PDF 提取及关键词检索在后台线程运行，双栏按几何位置恢复顺序。CMaps 支持 CID 中文 PDF；页码使用 PDF 物理页号。并发工作上限 2，常驻索引上限 4，关闭应用会清理工作线程。
- 选区最多 2,000 字符；证据按 UTF-8 字节数使用保守上界（默认 8,000 字节，最多 16 段），必需的选区上下文超限会明确拒绝，选区和必需正文不静默截断。近期最多 4 轮、5,000 字节历史作为对话资料，历史回答不作为论文证据。
- 单独的问答提示词和缓存，不经过翻译 schema。密钥沿用主进程加密配置，问答与翻译共用服务 QPS/并发预算，交互请求优先且最多连续插队两次。无自动付费重试。
- 主进程控制证据 ID 并校验引用；未知 ID 拦截，流式阶段的 ID 不可点击。回答区分论文陈述、推断和背景解释，缺少文字/图表证据时要求明确说明。资料中的指令不会获得工具或外部动作权限。
- 按请求、文档、版本及会话隔离事件；支持准备阶段与上游流式请求取消。旧请求完成只更新所属历史，不覆盖新选区。重复请求去重；一个会话同时只运行一个问题。
- 本地保存完整/停止/失败会话，支持恢复、查看与删除，保存回答会新增批注。问答用量独立记录并与当前翻译汇总；未报告用量标明未知。没有单价配置，不伪造金额。复制通过主进程剪贴板接口完成。

## 自动验证

- `npm test`：40 个测试文件、390 项通过，含问答服务、文档提取、传输和既有功能回归。
- `npm run build`：TypeScript 与 Electron 主进程、preload、worker、renderer 构建通过。
- `node scripts/question-smoke.mjs`：实际 Electron + PDF.js + 本机模拟服务通过。涵盖单词/句子点击、键盘入口、中文版本、未知引用拦截、出处跳转、追问、复制、保存备注、停止、429 手动重试、换选区取消、历史删除保留批注、侧栏局部延迟、流式期间 PDF 滚动和最小窗口控件边界。
- 100 个不同未知引用 ID 全部拦截。另有双栏顺序、跨页定义、扫描页、CID 中文、超长选区、必需证据超限、损坏历史隔离、用量写入失败仍保存答案、跨文档同请求 ID、启动阶段取消和 SSE 大事件等回归用例。
- 独立代码审查发现的取消、引用预算、中文提取、持久化、资源上限及响应大小问题已修复；界面审查发现的小窗口发送区溢出已修复。机械设计检测无发现。

实际界面测量、宽/窄/中文/最小窗口截图和局部延迟数据在 `output/playwright/questions/report.json` 及同目录 PNG。测量仅代表本机测试夹具；不据此承诺任意机器或远程模型的首字延迟。

## 尚未据此验证的指标

模拟服务用于验证程序行为，不能证明专业回答准确率 ≥90% 或引用语义支持率 ≥95%。原方案建议的 100 道真实论文人工评测尚未执行；100 个未知 ID 测试不等同于 100 道真实问题评测。执行该评测需要固定论文集、模型和人工标注。

不含第二期的可靠中英段落映射、术语卡片或联网检索；扫描件需先 OCR，首期不上传整页图片。复杂公式、图表内容仍可能是证据缺口。上下文使用保守字节上界；未配置服务商 tokenizer 或模型上下文元数据时，不声称已用真实 tokenizer 精确计数。
